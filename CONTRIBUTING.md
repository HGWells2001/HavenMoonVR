# Contributing

Bug reports from real VR hardware are especially useful. Include:

- headset and controller models;
- SteamVR version and controller driver;
- which hand and object were tested;
- whether the dim ray appeared;
- whether its direction, target dot and action were correct;
- any required height adjustment.

Do not attach or commit original Haven Moon files, game assemblies, assets, saves, Steam configuration files or Valve binaries. Small source changes and documentation improvements are welcome through issues or pull requests.

For Italian reports, the same information may be provided in Italian.
